# Sunleaf Digital Experience

Повноцінний застосунок на Next.js для бренду Sunleaf — мережі кави, чаю та десертів з wow-ефектом.

## Стек
- Next.js 14 (App Router, TypeScript)
- Tailwind CSS та Framer Motion для анімацій
- Власний API для Leafy з інтеграційним шаром

## Запуск
```bash
npm install
npm run dev
```

Для продакшену використовуйте `npm run build` та `npm start` або деплой на [Vercel](https://vercel.com/). Конфігурація `next.config.mjs` вже містить дозвіл на віддалені зображення.

## Структура
- `app/` — сторінки маркетингового сайту (головна, досвіди, локації, лояльність, Academy, корпоративні рішення), журнал та адмін-панель
- `app/api/` — серверні маршрути для меню, замовлень, локацій, досвідів та AI-асистента Leafy
- `components/` — UI-компоненти та інтерактивні блоки
- `data/` — демо-дані для меню, історій та метрик

## Налаштування AI-асистента
За замовчуванням Leafy відповідає на основі словника ключових слів. Для інтеграції з власною LLM можна оновити `app/api/assistant/route.ts` та використати OpenAI, Mistral чи інший API.
